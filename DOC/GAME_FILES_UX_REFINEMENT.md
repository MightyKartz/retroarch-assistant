# 游戏文件实施工单 · 单击浏览目录，直接复制游戏

**状态：待实施。** 适用于桌面端「游戏文件」页的电脑目录、直接挂载的 SD 卡和 USB 文件传输（MTP）存储。复现依据为 2026-11-20 的 Retroid Pocket Nova 截图和仓库实现。本单更新原计划中“文件页的添加文件沿用现有导入流程”的决定；拖放、扫描建库和播放列表管理继续按各自计划推进。[原实施计划](GAME_FILES_IMPLEMENTATION.md)

**交付目标。** 用户单击左侧 Games，逐级进入 ROMs › SFC，点「添加游戏文件…」，在系统文件选择器中选中两个 ROM 并确认。复制随即开始，当前目录始终可见。完成后用户能看到新增文件以及实际复制结果。

## 现状与受影响的调用方

| 位置 | 现有行为与实施依赖 |
| --- | --- |
| 文件页及游戏详情页 | 工作台从工具栏打开文件页，详情页还可传入目录和文件路径，要求自动定位并选中。目录行目前单击选中、双击进入，工具栏依赖选中项执行改名、删除和复制。调整点击行为时须保留这两个入口和操作能力。[文件页](../src/templates/game-files.js) · [详情页](../src/templates/game-browser.js) |
| 添加入口与游戏库 | 文件页的加号把当前路径交给 `openGameImport`。即使已确定目的地，也会加载游戏库配置、推断主机并触发分析。桌面端另有调用方使用完整导入流程，仍需支持启动路径配置和播放列表写入。[导入实现](../src/templates/game-management.js) · [桌面入口](../src/templates/desktop.js) |
| 目录与传输 | 目录接口返回面包屑，MTP 根节点缺少存储名称。现有复制接口处理本地之间或同一设备内的复制，遇到同名会另取副本名。从电脑直接向掌机添加文件需要支持本地源和 MTP 目标的组合。[目录与任务接口](../src/api_library.py) · [文件操作](../src/game_file_actions.py) · [上传实现](../src/mtp_runtime.py) |

## 实施项

1. **单击进入目录。** 单击文件夹图标或名称即可进入，键盘聚焦后按 Enter 执行相同操作。每个目录行提供可用键盘打开的「更多操作」按钮，菜单作用于该行，提供重命名、复制和删除，点击菜单时停留在当前目录。普通文件继续单击选中并使用原工具栏。保留删除确认、备份和已有的列表同步提示。
2. **明确复制目的地。** 尚未选择目录时，在列表中央显示「从左侧选择要存放游戏的目录」，禁用添加。进入目录后，用实际存储名称作为面包屑起点，例如「Games › ROMs › SFC」；上级目录按钮与可点击的路径层级继续可用。目录读取失败时显示原因，避免把上一个目录误作本次添加目标。
3. **从电脑直接添加。** 在当前目录显示带文字的主按钮「添加游戏文件…」，调用原生多文件选择器；旁边提供次级入口「添加文件夹…」，将所选文件夹连同原名和内部结构复制进当前目录。用户确认选择即提交复制任务，取消选择即返回原处。该动作只需要可写的目的地和源文件，无需主机、核心、Android 启动路径或播放列表配置。游戏库原有的完整导入入口继续可用。
4. **提供可核对的复制结果。** 通过已有后台任务显示进度，复用 MTP 的上传校验和取消机制。直接添加遇到同名文件时默认跳过并列出相对路径，已有文件保留原样；同名顶层文件夹按整项跳过，避免把两套光盘文件混合。普通「复制／粘贴」沿用原有副本命名规则。成功后刷新目录，让新增项可见并高亮；批量高亮与工具栏的单项操作分别处理。部分成功、取消或断连时分别报告已复制、已跳过、失败或未完成的项目，方便用户决定重试哪些文件。

## 验收清单

- [ ] **逐层导航。** 从 Games 进入 ROMs 再进入 SFC，每层只需单击一次。键盘可以进入目录、打开行菜单、返回上级；菜单操作作用于对应目录，即使此前选中了其他文件。
- [ ] **明确位置。** 同时存在内部存储和 Games 卡时，两处同名子目录显示不同的完整路径。未选择目录时有操作指引；已进入空目录时可以添加第一个游戏。
- [ ] **批量复制。** 分别在电脑目录、直接挂载的 SD 卡和真实 USB 掌机上，将两个 ROM 一次选入当前目录。核对目标文件内容，确认没有再次选择目标、没有进入主机配置、没有创建或改写播放列表。记录真机型号、存储位置及结果。
- [ ] **保留游戏结构。** 添加一个含 CUE、BIN 和子目录的游戏文件夹，核对目标文件夹名、相对路径及 CUE 引用。再次添加同一文件夹时报告跳过，原内容保持完整。
- [ ] **冲突与中断。** 两个源文件中有一个与目标同名时，只复制另一个，并列出跳过项。取消文件选择不启动任务；传输中取消或断开 USB 后，结果与目标中实际完成的文件一致，重新连接可重试。
- [ ] **入口回归。** 从详情页定位游戏仍能选中原文件；普通文件及目录仍可改名、复制和按既有确认流程删除；已有粘贴和完整导入仍按原规则工作。同步更新受影响的界面断言及文件操作测试。[浏览器冒烟用例](../tests/browser_smoke.cjs) · [界面结构测试](../tests/python/test_ui_information_architecture.py) · [文件操作测试](../tests/python/test_game_file_ops.py)
