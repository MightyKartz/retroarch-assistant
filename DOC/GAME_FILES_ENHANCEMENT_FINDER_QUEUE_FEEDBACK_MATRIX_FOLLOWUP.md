## 四格验收

| 新导航结果 | 先结算的请求 | 最终界面 |
| --- | --- | --- |
| 成功 | 旧刷新 | 落在新目录，两批结果均可查 |
| 成功 | 新导航 | 落在新目录，两批结果均可查 |
| 失败 | 旧刷新 | 具体读取错误和两批结果均可查 |
| 失败 | 新导航 | 具体读取错误和两批结果均可查 |

每格都要确认第一批恰好提交一次，提交参数只包含第一批的来源且落点正确，实际目标字节与来源一致，第二批目标文件不存在。恢复目录读取并返回目标目录后，列表显示第一批文件，提交次数保持为一，状态栏和详情均无旧提示重播。
