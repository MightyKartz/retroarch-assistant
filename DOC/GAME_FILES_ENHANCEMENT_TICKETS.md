## GF-01 · 名称列排序

目录接口目前已按文件夹优先、名称升序返回。将「名称」表头改为可用键盘操作的排序按钮，显示当前方向，并让辅助技术能读出方向。在文件页打开期间保留排序方向，使用已加载的目录数据重排。升序和降序都将文件夹置前，各组内部按名称排序。

- [ ] 初次打开保持原有顺序。点击或键盘激活表头能切换升降序，文件夹始终在文件前，两组均按方向重新排序。
- [ ] 排序无额外目录请求。定位选中、已有导入高亮和文件夹单击进入继续生效；与 GF-02 合并后，排序保留选中项，Shift 按新顺序取范围。

## GF-02 · 路径级多选

在 `game-files.js` 用完整项目路径保存当前目录选择及 Shift 锚点。普通文件单击选中一项，macOS 用 Cmd、Windows 用 Ctrl 追加或取消单项，Shift 按当前显示顺序选择连续范围，Esc 清空。用行首复选框提供可见且可用键盘操作的选择入口，文件夹名称的普通点击继续进入目录。显示选中数量，重命名只在选中一项时启用。行菜单操作仍作用于被点击的那一行。

- [ ] 文件和文件夹可以追加、取消及范围选择。键盘可操作复选框，并读出选中状态。
- [ ] 排序保留选择，刷新同一目录仅保留仍存在的项，切换目录清空选择与锚点。详情页定位仍选中并滚动到目标。
- [ ] 行菜单的改名、复制和删除作用于该行。多选复制和删除在 GF-03 交付后启用。

## GF-03 · 批量复制和删除

将文件页内部剪贴板扩为路径列表，保留先复制、再进入目标目录粘贴的工作流。批量请求在后端入口一次校验并归一化路径，沿用本地和同设备 MTP 的现有约束及禁止复制到自身子目录的规则。每批启动一个后台任务，顺序复用现有复制或删除实现。删除在任务开始前列出所选项并一次确认，明确文件夹内容会一并永久删除。

结果要能逐项区分成功、失败、部分完成和未执行，取消后按实际完成情况刷新。播放列表同步只登记已确认删除的项目。目录整项删除成功时可登记目录；部分删除时只登记已确认删除的文件路径，使仍存在的 ROM 保留列表引用。

- [ ] 复制多个文件或目录后只启动一个粘贴任务。同名项仍生成副本，刷新后按实际输出名称高亮；跨设备或不合法目标在写入前被拒绝。
- [ ] 删除多项只出现一次确认。取消确认时无写入；执行中断或遇到失败时，结果区分已删、部分完成、失败、未执行，并与磁盘或设备状态一致。
- [ ] 模拟目录删到一半后停止，打开列表同步预览，只移除已删除 ROM 的引用。保留单项操作和原有改名同步行为。

## GF-04 · 导入冲突预览与替换范围

将前端按目录快照比对同名的逻辑改为服务端导入预览。预览根据当前目标检查每个源，返回冲突项两侧的名称、类型、文件大小和修改时间。MTP 未提供的值显示「未知」，文件夹大小无需递归统计。同一批不同源映射到同一个目标时显示来源与冲突，保留明确选定的来源，避免输入顺序决定最终内容。

默认跳过同名项，支持逐项批准替换以及一次批准本次展示的冲突。文件夹明确提示整目录替换。执行沿用暂存后发布的实现，将覆盖授权绑定到预览中批准的源和目标，并在发布前复核目标。预览后新增的同名项，或已变化的批准目标，保留原样并在结果中说明。无冲突时沿用选完即复制的交互。

- [ ] 本地和模拟 MTP 的混合批次能并排显示大小、时间和类型。未知时间显示「未知」。文件夹冲突明确整项替换，原有目录不会被合并。
- [ ] 「跳过」保留原目标。逐项替换只覆盖批准项，其余非冲突项正常复制；同批两个同名源的处理与用户选择一致。
- [ ] 预览后新增同名目标，或在暂存期间改变已批准目标，执行结果应报告变化，目标内容保持完整。原有替换失败、残留路径及取消结果继续通过回归。

## GF-05 · macOS Finder 拖拽导入

先验证项目固定版本 pywebview 6.2.1 的实际 macOS 打包窗口能否通过 Python 侧 `DOMEventHandler` 取得完整 `pywebviewFullPath`。该版本按文件名关联原生路径与 DOM 文件，需核对多个同名来源和特殊字符。若验证发现路径缺失或错配，再评估从 Cocoa 拖放事件直接读取原生文件 URL。拖放接入复用 GF-04，桌面壳提供源路径，文件页锁定落点时可用的目标目录，再执行预览和复制。[pywebview 6.2.1 拖放示例](https://github.com/r0x0r/pywebview/blob/6.2.1/examples/drag_drop.py)

- [ ] 在 macOS 应用包中从 Finder 拖入单文件、多文件和带子目录的文件夹，核对源路径与目标字节。覆盖中文、空格、百分号及不同目录下同名源；无法确认完整路径时提示使用文件选择器。
- [ ] 落在有效列表上且无冲突时复制到落点目录，有冲突时打开共用预览。目标目录读取中、页面关闭或切换导致落点失效时，未确定的文件不写入其他目录。
- [ ] 选取和拖入同一批源得到一致的冲突与复制结果。浏览器模式和原生选择器入口继续工作。拖入文件只复制内容，播放列表仍由现有扫描或导入流程处理。
