## GF-04-R1 · 占用目标名后的写入仍可覆盖外部内容

**复现与影响**　在实际 ExFAT 卷上，排他重命名返回不支持，导入进入回退分支。文件分支用 `O_EXCL` 创建同名占位文件后关掉句柄，随后按路径写入。用测试钩子在关闭句柄后、写入前将占位文件换成内容不同的外部文件，执行结果为复制成功，外部内容被覆盖。目录分支占用顶层名称后逐项重命名子文件。在子文件发布前由外部创建同名成员，同样会被覆盖。

**修复建议**　让写入和失败清理只作用于任务已取得且能核对身份的对象。文件回退可继续使用独占创建后持有的句柄，发布结果应与最终目录内容一致。目录回退也要逐个拒绝已有子项。无法保证这些语义时保留外部对象，报告冲突或部分完成。保留常规无冲突导入和授权替换。[本地发布实现](../src/game_file_actions.py)

- [ ] 在实际 ExFAT 卷复验占名后被替换的文件。外部字节原样保留，结果报告实际发生的冲突或未发布状态。
- [ ] 创建顶层目录后、发布子项之前插入同名子文件。保留外部子文件，报告真实完成范围。中断清理只处理本任务拥有的对象。
- [ ] 最终发布前出现同名文件和空目录时仍能拒绝覆盖，无冲突文件与目录可正常复制。

## GF-04-R3 · 等长改写绕过 ExFAT 目录替换复核

**复现与影响**　在实际 ExFAT 卷上预览替换 `Game/`，其中 `keep.bin` 内容为 `aaaa`。预览后迅速原地改写为 `bbbb`，无需设置时间戳。大小与文件系统报告的修改时间均保持不变，目录签名相同。执行报告替换成功，更新后的 `keep.bin` 消失。

**修复建议**　批准整目录替换时，记录并在发布前复核足以区分内容的依据，按需使用分块摘要。仅凭路径、大小和修改时间会漏检实际卷上发生的更新。读取或核对失败时保留目标并说明原因。[目录签名与替换执行](../src/game_file_actions.py)

- [ ] 以等长、相同修改时间、不同内容的文件构造确定性回归，并在实际 ExFAT 卷复验。保留更新后的原文件，替换计数为零，结果注明变化或无法核对。
- [ ] 覆盖目标未变化时的正常替换，以及暂存写入期间出现的内容变化。暂存清理保留目标目录及其全部内容。

## GF-04-R2 · 可核对的嵌套 MTP 目录无法替换

**复现与影响**　模拟目标 `Game/Disc/game.bin`。所有文件均有对象 ID、大小和修改时间，预览前后一致。目录节点记录的时间固定为空，当前校验对所有节点一律要求修改时间，导致含任何子目录的目标被报告为「无法核对」。

**修复建议**　按节点类型核对所需依据。目录核对身份、相对路径和结构，文件继续核对可靠的身份与变更证据。保留二轮修复中对成员对象 ID 变化或文件未提供足够证据的拦截。[MTP 枚举与签名](../src/game_file_actions.py)

- [ ] 验证证据完整、含嵌套目录且未变化的目标可以按授权替换。
- [ ] 子目录身份或成员结构变化时保留目标。嵌套文件缺少可靠变更依据、或被同名等长的新 MTP 对象替换时仍能拦截。

## GF-05-R1 · 本次原生采集缺失时仍可能借用旧路径

**复现与影响**　在 A 与 B 各放一个同名、等长但内容不同的 `Game.sfc`。只在原生队列保留 A 的旧采集，模拟 B 的原生采集缺失，再提交 B 的 DOM 事件。配对函数返回 A 的路径。桥接回调仍带 B 的事件时间，前端会将它视作 B 落点的有效来源。

**修复建议**　原生采集、DOM 事件和前端落点须有可验证的同一次拖放关联。文件名和大小可用于核对成员，不能充当批次身份。缺少本次记录时提示使用「添加游戏」，不可消费历史记录。保留单次 URL 解码和前端旧落点拦截。[原生桥接](../src/desktop_window.py) · [前端落点校验](../src/templates/game-files.js)

- [ ] 复现同名等长、内容不同且本次采集缺失的场景。不触发导入预览或写入，也不消耗或错配其他有效事件。
- [ ] 覆盖逆序回调和连续拖放。每批来源与自己的落点配对。在实际 macOS 应用包中从 Finder 核对文件夹、特殊字符及同名文件的目标字节。

## GF-03-R2 · 部分复制只展示前四个已写入文件

**复现与影响**　向实际汇总函数传入五条已确认写入路径和断连原因。窗口只展示前四条及总数，第五条没有入口可查。用户无法据此核对实际写入范围。

**修复建议**　保留简短汇总，并增加可打开或展开的完整明细，使用后台返回的 `written`、`target` 和错误信息。保留取消、完整成功与未执行状态的现有展示。[粘贴结果展示](../src/templates/game-files.js)

- [ ] 以取消替代断连，完整明细与取消状态均正确。后续未运行的文件没有计入已写入路径。
